# Phase 2 最终结论：能源经营与全市场基础因子

## 主结论

Phase 2研究范围已经完成，但没有形成可部署策略。

Phase 2A否证了当前定义的能源经营surprise：2024Q3—2026Q2只有8个季度横截面，最高surprise纯多头组合净收益-5.01%，同期能源等权+4.53%、932047全收益指数+0.68%，平均20交易日rank IC为-0.4875。

Phase 2B发现20日动量是值得继续观察的市场候选，但证据不足以宣称alpha。2024-04-01至2026-09-02，月频top 20%纯多头组合在10万元本金、双向各万一、每笔最低5元和现金年化1.5%的口径下净收益16.39%，当前名单可交易等权为0.83%，932047全收益指数为3.45%。但其29个完整月份的平均20日rank IC只有0.0496，朴素t值1.075；当前名单回填历史还存在幸存者偏差。

因此当前正确动作不是上线交易，而是保存候选、关闭Phase 2调参，并继续补历史universe、资产类型、DPU和NAV时点数据库。

## 数据与时点

全市场冻结行情来自东方财富历史K线端点，保存后复权参数、抓取时点和universe快照日。快照共有50,863行，覆盖88只有历史行情的证券，日期从2021-06-21至2026-09-02。当前universe共94只；181001、508047、508605、508606、508607和508609由上游明确返回无历史，单独记录为`no_history`，没有生成替代值。

研究使用2026-08-28当前universe，并用每只证券首个行情日控制最短80个观察日。这个处理能避免新证券刚上市就进入因子，但不能替代真实历史成分表：仓库只有一个universe快照日，所以所有收益数字均标记为研究性结果。

932047使用中证REITs全收益指数，只作为市场比较基准，不作为持仓，也没有以其选样规则替代策略universe。

## 策略定义

全部策略只做多，不构造不可交易的空头组合：

1. 在每周或每月最后一个市场交易日收盘后计算因子；
2. 要求至少80个历史交易观察，且20日平均成交额不低于100万元；
3. 下一个932047交易日收盘买入因子最高的top 20%，等权持有；
4. 入选证券集合不变时不为微小权重漂移强制交易；
5. 组合成本按买卖双向各0.01%，基线另设每笔最低5元；现金年化收益1.5%；
6. 容量使用单只证券20日平均成交额的5%作简单压力近似，不等同于真实冲击成本模型。

因子包括20／60日动量、5日反转、20日成交额、Amihud非流动性、20日已实现波动率及四维等权组合。组合因子的四个维度是趋势、反转、流动性质量和低波，避免同时把成交额与非流动性当成两个完整权重。

## 稳健性而非挑优

20日动量月频top 10%／20%／30%在最低5元情景下净收益分别为22.15%、16.39%和14.44%，均高于932047；取消最低5元、只保留双向万一时分别为23.11%、18.75%和18.08%。周频只按比例佣金时三个分组均为正，但加入每笔最低5元后top 30%变为-0.98%，top 20%也落后932047。

这些结果说明月频动量不是单个top比例偶然挑出的，但不能消除当前universe偏差、多重因子检验、样本只有约两年半和IC显著性不足。

## 交易费用依据

上交所现行收费指引列示公募REITs竞价交易经手费为成交金额0.0045%双向；[2026年收费表](https://www.sse.com.cn/services/tradingservice/charge/ssecharge/c/c_20251231_10803655.shtml)显示试点期间暂免。投资者实际佣金由券商账户约定，[券商公开收费表](https://www.tebon.com.cn/main/businessGuide/economicBusiness/zqjyfgs/index.html)中可见公募REITs双向佣金和最低5元条款。因此本研究把用户指定的双向各万一作为费率，并把最低5元视作可配置券商情景，而不是交易所统一事实。公募REITs交易暂不收印花税；投资者教育资料可见[中国投资者网说明](https://www.investor.org.cn/xxzx/tjzl/tjnrgmjytx/bk/kj/jyxl_3799/202311/P020231123539558246482.pdf)。

## Phase 2关闭条件

已完成的部分包括能源PIT特征、公告后纯多头检验、全市场价格与成交额冻结、周／月频基础因子、真实成本、932047比较、容量近似、参数与费用敏感性和明确数据闸门。无法可靠完成的资产类型中性、分派收益率、P/NAV与国债利差已经以失败闸门交付，不再用假设数字补齐。

Phase 3已经完成高速、物流和能源的跨资产经营PIT扩面。交易所正式上市公告现已重建63个月末成员；分派、基金份额和NAV闸门仍未通过。其结果见[Phase 3最终结论](phase3_findings.md)。20日动量只作为预注册候选在新增样本上检验，不再用当前区间继续调参。
