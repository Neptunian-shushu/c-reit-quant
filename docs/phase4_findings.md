# Phase 4：基金时点数据库与联合模型结论

## 主结论

Phase 4的数据库与研究闭环已经完成，但策略仍不能部署。

本阶段为8只跨资产样本新增105份季度报告的份额与可供分配金额、28条年末NAV、76次实际分派，以及8,098行不复权价格。所有基金指标均来自交易所公告目录中的正式PDF；原始PDF不入库。413条观测标记为`machine_extracted_official_pdf`，另有6条无文字层扫描公告经逐页视觉核对后标记为`visual_verified_official_pdf`。两者都不冒充独立人工复核。

固定联合模型把四项信息等权合成：经营surprise、过去一年实际DPU收益率、NAV/price和20日含分派动量。每季度等待经营报告全部到齐后，在下一共同交易日收盘持有得分最高2只；不做空。10万元组合采用买卖双向各万一、每笔最低5元和现金年化1.5%，932047只作为全收益基准。

2024-10-28至2026-09-02的样本内重放结果为：

| 组合 | 净收益 | 最大回撤 |
|---|---:|---:|
| Phase 4联合top-2 | 11.19% | -5.19% |
| 当期合资格REIT等权 | 2.11% | -10.76% |
| 932047全收益指数 | 0.68% | -17.52% |

联合得分的20交易日平均rank IC只有0.041，8期中4期为正；联合收益还略低于经营单因子top-2的11.38%。这没有证明DPU、NAV和动量带来增量alpha。正收益不能弥补样本过短、同区间研究和独立复核不足等问题。

## 数据建设结果

- `phase4_fund_fundamentals.csv`：343条long-format观测，其中315条来自季度报告，28条为年报直接披露NAV；
- `phase4_distributions.csv`：76次真实分派，统一为每份DPU，并保存公告日和场内除息日；
- `phase4_distribution_visual_overrides.csv`：508028的6份扫描型公告逐页视觉核对结果；自动排除表已清零；
- `phase4_unadjusted_prices.csv`：8只证券共8,098行不复权日线，用于历史DPU yield和P/NAV；
- 收益回测继续使用后复权价格，估值信号绝不使用后复权价格水平。

季度可供分配金额、基金份额与单位可供分配金额已做勾稽。508096在2025Q1只把单位金额披露到小数点后两位，因此采用与披露精度一致的0.0051元容差；其余差异通常不超过四位小数舍入范围。

实际DPU与“单位可供分配金额”是两个不同事实：前者来自收益分配公告，后者来自季度报告。数据库和模型没有将二者混用。

## 联合模型定义

每个季度的决策日为该季度合资格经营报告的最晚公告日。信号只读取该日或此前已公开的数据：

1. 经营surprise：Phase 3固定定义；
2. TTM DPU yield：决策日前365天内已经除息、且公告日在决策日之前的每份分派合计／不复权价格；
3. NAV/price：最近一份已公开年报直接披露的每份NAV／不复权价格；
4. 20日含分派动量：不复权价格变化加窗口内已除息DPU。

四项各自在当期横截面转为百分位排名，再等权平均。没有为获得更好结果优化权重。资料不完整的证券当期退出合资格集合，每期仍要求至少6只。

## 稳健性与容量

固定对照结果如下：经营、DPU yield、NAV/price和动量单因子top-2净收益分别为11.38%、5.85%、6.99%和7.00%；联合top-1为-2.71%，联合top-3为7.51%。把佣金提高到双向各5bp后，联合top-2净收益为10.66%。持仓数变化会显著改变结论，且全部结果来自同一短区间，不能视为独立验证。

按每只入选证券过去20日平均成交额的5%参与率、等权配置估算，8次组合的容量下限约为41.61万元，明显低于机构可部署规模。这只是成交额启发式上限，未模拟冲击成本、涨跌停、盘口深度和大宗交易。

## 新发现的风险

- 后复权历史价格会因后来分派改变过去的价格尺度，不能用于历史收益率型估值；本阶段因此单独冻结不复权价格。
- 508028部分分派PDF为扫描件，无文字层；本阶段已逐页核对，但仍需独立人工二次复核。
- NAV主要来自年报，季度之间会陈旧；P/NAV不是资产实时评估折价。
- 扩募会改变基金份额、资产边界和NAV可比性。180301、508056和508096已经出现份额跳变，模型只能使用公告时点版本。
- 当前8期与Phase 3研究区间重叠，不是规则冻结后的真正样本外检验。
- 932047是全市场REIT全收益基准，而本组合仅覆盖8只且资产类型不均衡；等权合资格组合是更直接的第二基准。
