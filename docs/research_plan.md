# 研究计划

## Phase 0：数据可得性验证（已完成）

已交付：

- C-REIT 全市场实时行情／名录和单只日线接口；
- 历史再分析天气与历史预报的独立客户端；
- 定期报告 long-format 标准结构和候选指标提取框架；
- 高速公路、水电、仓储物流三类正式报告样本；
- 可行性运行脚本、离线测试和风险文档。

结论：公开数据总体可行；标准化经营基本面面板是主要瓶颈，也是潜在壁垒。

## Phase 1：水电研究闭环 508026（已完成）

当前工程优先级已调整为数据库优先：先扩大证券、公告、资产和经营指标的可追溯覆盖，再继续预测模型或策略优化。

第一轮已完成：

- 2024Q2—2026Q2连续9个季度经营指标；
- 2013—2022年10个完整年度和2023年1—9月共55条上市前经营观测；
- 电站、1642平方公里集水区、九龙河和溪古水库4条水文关系；
- 2013Q1—2026Q2共54季度固定ERA5点位再分析天气；
- MERIT自动候选流域、文件指纹、许可和17.54%面积偏差审计；
- 8个ERA5网格的候选流域面积权重及2013—2022季度再分析天气；
- 2024Q2—2026Q2固定GFS global提前24小时历史预报，共19,704小时；
- 2018—2022扩展窗口年度模型比较，天气模型未战胜历史均值；
- 发电量、利用小时、结算电量、不含税结算电价四项核心字段；
- 资产坐标、点位天气季度聚合和经营数据连接；
- 连续性、缺失和最小样本量检查。
- 一个不拟合参数、508026／现金切换的纯多头发电量同比事件回测。
- 证券、资产、指标字典、来源文档、经营观测和分派记录的第一版关系审计。
- 2026-08-28 全市场 94 只证券观察快照及增量合并流程；
- 公告哈希、抓取元数据、更正血缘和全市场质量队列；
- 沪深交易所8,164条官方公告目录，覆盖95个代码（含新增未上市508095），并识别1,131条定期报告候选；
- 高速公路、水电、仓储物流三类规范数据库种子。
- 508018与508056共55份连续定期报告登记及哈希，并人工核验2026Q2核心经营指标。
- 能源扩面覆盖3只REIT、6项底层资产和39条2026Q2经营观测；
- 508028海上风电形成2023Q2—2026Q2连续13季度发电量面板和86条经营观测。
- 508096光伏／扩募水电形成146条观测，180401燃气发电形成16季度、75条观测；能源纵向面板合计307条。
- 43份实际使用来源进入复核台账，508096年报修订形成3条可复现的point-in-time版本。
- 完成36项2025年季度—年报勾稽，覆盖508026及三条能源扩面，显式区分完全一致、披露精度差异、年报调整和口径差异。
- 能源事件表记录扩募、外部停机和电价／市场机制变化共6条。

Phase 1研究流程已经完成，程序化状态为`phase1_research_complete=true`。可部署闸门要求至少12个连续季度、可信流域边界且天气模型战胜简单基线；当前上市后只有9季度，MERIT候选流域面积偏大17.54%，天气OLS样本外落后均值，因此`deployable_nowcast_ready=false`。

探索性事件策略按2026Q2更新后共有5个事件：按双向各万一佣金，策略跑赢基准但落后508026含分派买入持有，仅2次仓位选择有利。这提供了更直接的反证：不能把发电量同比符号当成稳定信号，但仍值得继续建设水文 nowcast 和横截面基本面数据库。

后续对508026只做数据维护：追加季度报告、用更准确坝址或官方边界替换实验流域、补充来水和水库调度。除非数据通过闸门，不在10个年度样本上继续增加模型复杂度。

## Phase 2A：能源经营surprise横截面（已完成）

已把508026、508028、508096和180401的343条经营版本整理为35条稳定资产范围的point-in-time同比特征。508096只使用两项首发光伏资产，避免2025年末扩募水电改变组合边界；四季度前值按每次公告日实际有效版本读取。

2024Q3—2026Q2形成8个至少含3只证券的横截面。固定20交易日前瞻收益平均rank IC为-0.4875，8期均不为正；最高surprise纯多头组合净收益-5.01%，落后能源等权+4.53%和932047全收益+0.68%。因此简单同比减历史均值的surprise被否证，不进入生产策略。

## Phase 2B：基础市场与估值因子（已完成研究边界）

已对当前名单中88只有真实历史行情的证券测试月频／周频动量、短期反转、成交额、非流动性、已实现波动率和四维组合。全部组合只做多top组，不使用空头；交易成本采用双向各万一、基线每笔最低5元，现金年化1.5%，以932047全收益指数比较。

月频20日动量top 20%净收益16.39%，高于当前名单等权0.83%和932047的3.45%，但29个月平均rank IC只有0.0496、朴素t值1.075。正式上市公告已重建63个月末成员；资产类型仅11／94人工核验，DPU时点和NAV尚未扩至全市场，国债vintage为0，因此相关因子仍以数据闸门失败结束，没有填入假值。Phase 2整体研究范围至此关闭，策略不部署。

## Phase 3：数据库扩面与经营预期模型（已完成）

已新增180201、508018、180301和508056四条季度经营面板，共110条人工核验观测。508056只使用2023年扩募后的十项资产组合，180301只使用首发现代物流中心；508018因通行费税基变化，只把日均自然车流用于主特征。

与四只能源REIT合并后形成73条PIT同比特征和2024Q3—2026Q2共8个至少含6只证券的横截面。季度top-2净收益11.38%，合资格证券等权2.11%，932047全收益0.68%。平均20日rank IC仅0.02且横截面少于12期；历史成员闸门虽已通过，策略仍不部署。

Phase 3以失败部署闸门关闭：研究链路完整，正收益候选保留，DPU、NAV、基金份额和历史证券状态缺口不以假值填补。详细结果见[Phase 3最终结论](phase3_findings.md)。

## Phase 4：数据成熟度与可交易模型（研究闭环已完成，未部署）

已为8只跨资产样本整理105份季度报告、343条基金指标、28条年末NAV、76次实际分派和8,098行不复权行情。6份无文字层扫描公告已逐页视觉复核。估值使用不复权价格，收益回测使用后复权价格；单位可供分配金额与实际DPU分开存储。固定联合模型等权合成经营surprise、TTM DPU yield、NAV/price和20日含分派动量。

联合top-2在2024-10-28至2026-09-02净收益11.19%，合资格等权2.11%，932047全收益0.68%；平均20日rank IC仅0.041。联合模型还略低于固定经营单因子top-2的11.38%，没有证明增加估值和动量带来增量信息。结果属于同区间研究重放，不是前瞻样本外证据。

扫描公告、历史成员和209个来源哈希缺口已经关闭；部署闸门仍失败：联合横截面只有8期、419条观测独立复核为0、规则冻结后的新增季度为0。Phase 4因此以“数据库闭环完成、策略不部署”关闭，详见[Phase 4结论](phase4_findings.md)。

后续前瞻维护链路仍是：

`t 时点公开信息 → 预测 DPU／经营超预期 → 预期收益排序`

必要保护措施：

- 使用报告真实发布日期；
- 不使用缺少 vintage 控制的未来修订宏观数据；
- 严格回测使用历史时点真实可得的天气预报，而非事后再分析天气；
- 保留退市、扩募和资产边界变化历史。
- Phase 2月频20日动量、Phase 3经营surprise及Phase 4联合top-2只在新增样本复核，不在原区间继续挑参。
