## 能源扩面

能源横截面种子覆盖508028、508096和180401共6项底层资产，2026Q2核心指标覆盖22/24。两个缺口都是508096水电项目只披露含税结算均价，数据库没有自行反推不含税值。

508028海上风电已形成2023Q2—2026Q2连续13季度发电量面板，共86条观测，核心覆盖41/52。结算电量自2024Q3、组合利用小时自2024Q4开始稳定披露；报告内平均风速有11期。19份定期报告均已登记并计算哈希，13份季度报告被实际使用。2025年年报和2026Q2季度报告已人工核验；其余早期报告仍保持`metadata_verified`，在独立二次复核前不升级核验等级。

508096形成146条项目级观测。两项光伏资产在13个季度均有结算电量与含税结算均价，2024Q4起才有完整运营表；两项扩募水电从2025年12月27日起计入，首期不是完整季度。2025年报按最新账单修订3项短季度结算值，季度初值没有被覆盖。核心覆盖98/128（76.6%），缺口主要是早期披露断点和水电含税／不含税口径不一致。

180401形成75条项目级观测。实际上网／结算电量与收入覆盖16个季度，LNG吨数覆盖15期；2024Q4起有连续完整核心表。核心覆盖37/64（57.8%）。2023Q1只披露LNG体积，数据库未使用未经披露的密度参数换算成吨。

三条纵向面板使用的43份季度／年度来源都进入复核台账。3份最新季度来源已和独立维护的2026Q2横截面表核对一致；其余40份来源仍是单人第一轮复核，不宣称完成独立二次复核。

## Phase 2能源PIT横截面

508026、508028、508096和180401已登记稳定资产范围及主经营指标。343条经营版本形成35条可同比PIT特征；508096只使用两项首发光伏资产，扩募水电没有被错误计入历史增长。

35条特征中5条的当前值和同比基数全部连接到`human_verified`来源；其余30条明确标记为包含尚未升级来源登记状态的早期报告。它们已经完成单人转录复核，但不能在独立二次复核完成前称为生产级数据。

2024Q3—2026Q2形成8个至少包含3只证券的横截面和28条排名。每期等待入选报告全部公开，下一共同交易日收盘换仓。按双向各万一、每笔最低5元和现金年化1.5%，最高surprise组合净收益-5.01%，能源等权+4.53%，932047全收益+0.68%。固定20交易日前瞻收益平均rank IC为-0.4875，8期均不为正。当前结果否证简单surprise，不能解释为经营数据没有价值。

2025年勾稽表对508026水电、508028海上风电、508096四项资产和180401燃气项目执行36项季度—年报核对。508026结算电量和结算电价、180401售电收入共3项`annual_true_up`，均因年报没有季度归属而不改写季度值。508028的季度“结算电量”依据阶段性结算单，年报同名指标则定义为登陆点电表累计输出电量，形成71.50万千瓦时的`basis_difference`。其余差异为零或处在原公告披露精度内。

## 508026上市前与水文扩展

招募说明书形成2013—2022年10年年度历史，包括发电量、利用小时、来水可发电量和弃水量；2016年起另有上网电量，2021—2022年有平均来水量。2023年1—9月数据独立标记为`year_to_date`，没有当作完整年度。所有这些值在2024年2月27日才随招募说明书公开，因此不能用于构造更早交易信号。

天气快照固定Open-Meteo ERA5模型，避免默认best-match跨期换模。其网格中心为28.75、101.75，与请求的公开电站坐标不同属于再分析网格对齐，不是坐标错误。点位年度降水与来水可发电量的样本相关系数约0.09。

MERIT-Hydro／MERIT-Basins自动候选流域已生成并登记SHA-256和CC-BY-NC-SA 4.0许可。候选面积1930平方公里，较招募说明书1642平方公里高17.54%，状态固定为`experimental_area_mismatch`。8个ERA5网格的面积加权降水把全样本相关系数提高到约0.18，但2018—2022扩展窗口MAE为4578.56万千瓦时，仍差于历史均值3783.36万千瓦时。

固定提前期层使用Open-Meteo Previous Runs API的`gfs_global`和`_previous_day1`，覆盖上市后9个季度、19,704小时。相对同季度点位ERA5，累计降水相关系数0.980、季度MAE 38.29毫米、平均偏差-27.27毫米。它解决了“拼接预报没有固定提前期”的问题，但仍是点位预报，且模型计算发布延迟需要额外安全缓冲。

## Point-in-time 与修订

经营观测可以按 `as_of` 日期恢复当时可见版本。更正公告会产生新 `observation_id`，旧版本的 `valid_to` 等于新版本 `valid_from`，新版本通过 `supersedes_observation_id` 指向旧版本。

508096已出现首个完整可验证修订链：2026年1月22日季度报告给出的两座水电站短季度结算初值，在2026年3月31日年报中按最新账单更新，共形成3条修订版本。指定`as_of=2026-02-01`仍会返回初值，`as_of=2026-04-01`则返回年报值。

508026 的 2024Q2 当前只有更正稿和后续报告交叉核验值，被更正的原始版本尚未可靠取得。因此其修订计数仍为 0；这表示证据缺口，不表示历史上没有发生更正。

## 数据源风险

- AKShare 的 universe 接口曾成功返回 94 行，但随后的重复请求出现代理断开和东方财富 HTTP 主动断开；快照更新命令支持离线重建，失败时不会覆盖已有数据。
- AKShare后复权接口还会先请求全ETF代码映射，该步骤可能在历史K线可用时单独失败。市场模块已增加按沪市1／深市0直接请求同一K线端点的fallback，并保存实际抓取快照；未来刷新不得静默覆盖本次研究版本。
- 全市场冻结时Python HTTPS与东方财富连接多次被远端关闭；最终用逐证券校验缓存完成88只有历史行情的证券，6个空响应状态单独保存。该端点适合可重试研究抓取，不适合作为无缓存的生产依赖。
- 上交所和深交所公告接口均为交易所网页使用的公开接口，前端参数或响应字段仍可能改变；目录合并会拒绝同 ID 内容冲突，离线快照可重分类。
- `first_observed_date` 不是上市日期。只有持续积累快照并核对交易所资料后，才能形成历史证券状态表。
- SHA-256 能检测后续响应内容是否变化，但仓库不保存原 PDF；若未来需要完全离线重现，应在仓库外受控存储原文档。
- 资产类型关键词分类不能进入正式研究面板，必须经过人工核验覆盖层升级。
- Open-Meteo默认best-match可能在历史中切换模型；长期天气面板必须固定模型并保存模型名。固定ERA5仍属于事后再分析，不能用于严格交易回测。
- Open-Meteo免费接口按计算量限流，十年多网格抓取必须逐点缓存、校验完整日历并支持断点恢复；本次数据在429后由缓存补齐，没有用插值替代。
- MERIT自动边界依赖出水口坐标和河道吸附。当前公开坐标可能是厂房位置，面积误差已阻止该边界进入正式模型层。

## Phase 1之后的数据库工作

1. 从 1,131 条交易所候选中按证券逐步复核季度、半年和年度报告，而不是一次性下载全部 PDF；
2. 优先扩展水电／新能源、高速公路、产业园／物流各 2—3 只标的；
3. 给公告提取增加页码、表格位置、原始文本和复核时间；
4. 为扩募、购入资产、基金更名建立带生效日期的事件表；
5. 持续追加 universe 快照，逐步构建真实历史状态。
6. 对三条能源连续面板执行独立二次复核，并持续登记扩募、检修和市场机制事件；
7. 以同类第二只标的验证能源指标能否横截面对齐，避免数据库只适配单一报告模板。
