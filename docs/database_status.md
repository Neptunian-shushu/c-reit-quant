## 能源扩面

能源横截面种子覆盖508028、508096和180401共6项底层资产，2026Q2核心指标覆盖22/24。两个缺口都是508096水电项目只披露含税结算均价，数据库没有自行反推不含税值。

508028海上风电已形成2023Q2—2026Q2连续13季度发电量面板，共86条观测，核心覆盖41/52。结算电量自2024Q3、组合利用小时自2024Q4开始稳定披露；报告内平均风速有11期。19份定期报告均已登记并计算哈希，13份季度报告被实际使用。除2026Q2外，早期报告仍保持`metadata_verified`，在独立二次复核前不升级核验等级。

508096形成146条项目级观测。两项光伏资产在13个季度均有结算电量与含税结算均价，2024Q4起才有完整运营表；两项扩募水电从2025年12月27日起计入，首期不是完整季度。2025年报按最新账单修订3项短季度结算值，季度初值没有被覆盖。核心覆盖98/128（76.6%），缺口主要是早期披露断点和水电含税／不含税口径不一致。

180401形成75条项目级观测。实际上网／结算电量与收入覆盖16个季度，LNG吨数覆盖15期；2024Q4起有连续完整核心表。核心覆盖37/64（57.8%）。2023Q1只披露LNG体积，数据库未使用未经披露的密度参数换算成吨。

三条纵向面板使用的43份季度／年度来源都进入复核台账。3份最新季度来源已和独立维护的2026Q2横截面表核对一致；其余40份来源仍是单人第一轮复核，不宣称完成独立二次复核。

## Point-in-time 与修订

经营观测可以按 `as_of` 日期恢复当时可见版本。更正公告会产生新 `observation_id`，旧版本的 `valid_to` 等于新版本 `valid_from`，新版本通过 `supersedes_observation_id` 指向旧版本。

508096已出现首个完整可验证修订链：2026年1月22日季度报告给出的两座水电站短季度结算初值，在2026年3月31日年报中按最新账单更新，共形成3条修订版本。指定`as_of=2026-02-01`仍会返回初值，`as_of=2026-04-01`则返回年报值。

508026 的 2024Q2 当前只有更正稿和后续报告交叉核验值，被更正的原始版本尚未可靠取得。因此其修订计数仍为 0；这表示证据缺口，不表示历史上没有发生更正。

## 数据源风险

- AKShare 的 universe 接口曾成功返回 94 行，但随后的重复请求出现代理断开和东方财富 HTTP 主动断开；快照更新命令支持离线重建，失败时不会覆盖已有数据。
- 上交所和深交所公告接口均为交易所网页使用的公开接口，前端参数或响应字段仍可能改变；目录合并会拒绝同 ID 内容冲突，离线快照可重分类。
- `first_observed_date` 不是上市日期。只有持续积累快照并核对交易所资料后，才能形成历史证券状态表。
- SHA-256 能检测后续响应内容是否变化，但仓库不保存原 PDF；若未来需要完全离线重现，应在仓库外受控存储原文档。
- 资产类型关键词分类不能进入正式研究面板，必须经过人工核验覆盖层升级。
