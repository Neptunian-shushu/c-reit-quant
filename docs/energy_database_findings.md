# 能源类 REIT 数据库扩面结论

## 当前结论

能源类 REIT 不能作为单一资产类型处理。首批扩面已经确认四种底层业态：海上风电、集中式光伏、引水式水电和燃气发电。它们共享发电量、结算电量和电价等结果指标，但资源驱动、成本结构和适用另类数据不同。

仓库当前有四项互补数据产品：

- `energy_operating_metrics.csv`：3只REIT、6项底层资产、39条2026Q2横截面经营观测；
- `508028_quarterly_operating_metrics.csv`：海上风电2023Q2—2026Q2连续13季度、86条经营观测；
- `508096_quarterly_operating_metrics.csv`：光伏及扩募水电2023Q2—2026Q2共146条经营观测；
- `180401_quarterly_operating_metrics.csv`：燃气发电2022Q3—2026Q2连续16季度、75条经营观测。

所有来源均为交易所正式定期报告。508028、508096和180401共61份报告已经登记并计算SHA-256；三条面板实际使用43份季度／年度报告，全部完成第一轮人工复核并登记于`panel_quality_reviews.csv`，最新季度另与横截面表交叉核对。仓库不保存原始PDF。“第一轮复核”不等于独立双人复核，来源登记也不会因此批量升级为`human_verified`。

## 横截面覆盖

首批资产包括：

| 标的 | 底层资产 | 类型 |
|---|---|---|
| 508028 | 滨海北H1和H2项目组合 | 海上风电 |
| 508096 | 湖北随州、榆林项目 | 光伏 |
| 508096 | 苏家河口、松山河口项目 | 水电 |
| 180401 | 东部电厂一期 | 燃气发电 |

2026Q2核心指标覆盖为22/24。两个缺口来自508096两座水电站只披露含税结算均价，而水电试点规范核心字段是不含税结算电价。数据库没有自行除税或猜测税率。

## 508028连续面板

508028的发电量、上网电量、含税电价和项目发电收入覆盖13个连续季度。结算电量自2024Q3开始稳定披露，等效利用小时自2024Q4开始稳定披露，报告内项目平均风速覆盖11个季度。

核心覆盖为41/52。缺口主要集中于早期报告没有披露结算电量和组合口径利用小时。后期报告比较栏可能提供早期同期值，但当前关系校验要求观测期与来源报告期一致，因此没有把后见披露值回填成当时可得信息。

508028已达到项目设置的12季度最低样本门槛，但这只是工程门槛，不意味着样本足以支持可靠机器学习。平均风速仅11期，而且2025Q3存在配合电网停机14天的明确运营事件，建模时必须作为异常驱动或停机变量处理。

作为数据合理性检查，在发电量与报告内平均风速同时存在的11个季度中，二者Pearson相关系数约为0.934；剔除2025Q3外部停机季度后约为0.940。方向符合风电物理逻辑，但该结果同时包含季节性，样本极小、没有样本外验证，也不代表因果关系或可交易alpha。

## 508096光伏与扩募水电面板

两项原有光伏资产自2023Q2起有连续项目级结算电量和含税结算均价。2024Q4前的报告没有稳定披露项目级发电量、等效利用小时和设备利用率，因此数据库只记录当期可核验的两项指标，没有利用后期报告的同比栏反向填充。

自2024Q4起，项目表稳定提供设备利用率、发电量、等效利用小时、结算电量、含税结算均价和含税结算电费。两项扩募水电资产自2025年12月27日起纳入经营指标，2025Q4数据只覆盖12月27—31日，所有相关行均标记为“非完整季度”。2026Q1和2026Q2才是完整季度。2025年报根据最新结算账单更新了该短季度的3项值，数据库保留季度报告初值和年报修订值，并以2026年3月31日作为新版本生效日。

按资产类型核心要求计算，面板覆盖98/128，即76.6%。这一比例同时反映两个真实断点：早期光伏披露不完整，以及水电只披露含税均价、没有规范所需的不含税均价。不能通过估税或后见值把缺口“修漂亮”。

## 180401燃气发电面板

项目实际上网／结算电量和不含税售电收入覆盖2022Q3—2026Q2全部16个季度；LNG吨数覆盖15个季度，2023Q1报告只给出体积口径，因此没有擅自换算为吨。2024Q4起报告形成完整表格，连续披露发电量、整数等效利用小时、结算电量、含税平均结算电价、收入、LNG用量和含税单位燃料成本。

按四项核心指标计算，覆盖37/64，即57.8%。缺口集中于2024Q4之前没有当期披露的发电量、利用小时和精确含税结算电价。2022Q3只计入7月13日交割日至9月30日，也已标记为非完整季度。

## 季度与年报勾稽

2025年共完成32项勾稽：19项完全一致，11项差异可由季度报告按0.01亿千瓦时、0.01亿元或约数披露解释。180401有1项年报调整，其全年售电收入比季度暂估合计高14,700.36元；年报没有披露差额属于哪个季度，因此数据库只登记年度差异，没有任意修改季度值。508028另有1项口径差异：季度“结算电量”依据阶段性结算单，年报同名指标按登陆点电表累计输出电量定义，不能当作普通修订。

勾稽程序会从面板重算季度合计或加权均价，并校验年报证券、年度、发布日期和正式来源。这样可以同时发现转录错误、低精度舍入和年末暂估调整。

## 口径风险

- “上网电价”“结算电价”和“市场交易电价”不是同一概念；
- 含税结算电费与财务报表不含税发电收入已经拆成不同指标；
- 部分季度结算电量、电费包含当月财务暂估；
- 508096在2025年末扩募购入水电，扩募前后基金组合不可直接同比；
- 光伏和水电报告值部分只保留到0.01亿千瓦时，规范换算不能恢复更高精度；
- 508028早期报告目前完成单次转录检查，但来源登记仍保持`metadata_verified`，在二次逐项复核前不升级为`human_verified`。
- 2025Q3配合电网停机14天、508096扩募、榆林两次外部电网检修、湖北现货市场正式运行和2026年电价机制变化已进入独立事件表，建模时不能把这些结构变化归因于天气。

## 下一步

1. 对三条纵向面板的40份单次复核来源执行独立第二轮复核；
2. 为508028建立海上风场边界和轮毂高度风速连接，为508096建立辐照与水电流域映射；
3. 为180401补充可公开验证的LNG供应合同、检修和售电结构事件；
4. 持续追加新季度，禁止用后期比较栏覆盖历史信息集；
5. 扩展第二批能源REIT，检验同类指标是否能真正横截面对齐；
6. 在样本和信息时点审计完成后，先测试季节基线和简单线性模型。
